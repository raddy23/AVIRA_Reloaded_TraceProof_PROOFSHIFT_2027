# Final submission steps

1. Verify `pnpm.cmd exec tsc --noEmit`, start `pnpm.cmd dev`, open `/traceproof`.
2. Show Purpose, JSON/CSV upload, Analyze Evidence, human approval, what-if graph and export.
3. In `/home` show a real AI `analyze-trace` tool invocation with the same evidence.
4. Use **Clips** to record the real application; make the recording public and confirm it opens without login.
5. Create optional public GitHub repository and push the **complete integrated Agent-Native starter**, not merely this overlay. Exclude secrets and private data.
6. Optional: upload the included PPT to a shareable service and use its public Slides URL.
7. Submit at https://www.builder.io/hackathon/submit (name, contact, description, optional project URL, required public Clips URL, optional Slides URL). Accept rules and save confirmation.

## Suggested description
AVIRA TraceProof is an Agent-Native human–AI investigation workspace for supported structured timing evidence. A shared action measures request-response deadlines, the AI helps interpret evidence, and the engineer reviews and approves a bounded synthetic what-if experiment. Graphical comparisons and exportable reports explain observed facts, simulation assumptions and uncertainty. Demonstrated with synthetic e-commerce and automotive timing scenarios. Not a production root-cause or repair system.
